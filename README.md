# N-Queens Solver

This project provides an implementation of the classic **N-Queens problem**, a well-known task in algorithmics and combinatorics.  
The goal is to place **N queens** on an **N×N chessboard** so that no two queens attack each other.

---

## Problem Description

A queen in chess can attack horizontally, vertically, and diagonally.  
The challenge is to find all valid configurations where every queen is safe.

The problem is famous in:
- backtracking algorithms,
- recursion methodology,
- constraint satisfaction systems,
- AI and search strategies.

---

## Features

- Solves the N-Queens problem for any N ≥ 1.
- Backtracking-based algorithm.
- Supports printing:
  - all valid board configurations,
  - total count of solutions.
- Easily extendable to visualizers or GUI.
- Clear, optimized logic.
